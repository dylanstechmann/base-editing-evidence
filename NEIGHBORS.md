# Sibling repositories

`AGENTS.md` points here. Directories next to this repository in the shared
workspace are separate projects with their own Git histories. They are
pattern sources for keeping evidence, code and claims apart. They are not
evidence sources for this catalog.

Do not import their protocols, scores, dosing language, guide designs or
rejuvenation claims as base-editing outcomes. A sibling result does not
fill a missing domain in `data/outcomes.json`.

Local directories beside this repository include `regen-workbench`,
`regen-benchmark-kit`, `geroscience-compound-atlas`,
`senescence-module-score`, `senolytic-likeness-screen`,
`longevity-review-2026-10-03`, `longevity-review-2026-10-04`,
`iris-color-without-contacts`, `anagen`, `artificial-womb-models`,
`cell-protocol-compiler`, `organoid-oxygen-lab`, `organoid-phenotyping`,
`brightfield-colony-qc` and `pbmc3k-atlas-slice`. This list is a workspace
map, not a review of those projects.

The public ResearchDesk dental-track link in the README stays a pointer to
a separate outcome-domain discussion. It is not a source card.
